# DevTab

DevTab is a Stardance Hack Club project built with Vite, vanilla JavaScript, HTML, and CSS.

The project is currently in its initial setup phase. Features and the complete interface will be added in later commits.

## Local development

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm run dev
   ```

3. Open the local URL shown in the terminal (normally `http://localhost:5173`).

## Commands

- `npm run dev` starts the local development server.
- `npm run build` creates a production build in `dist/`.
- `npm run preview` previews the production build locally.

## Tech stack

- HTML
- CSS
- Vanilla JavaScript
- Vite
